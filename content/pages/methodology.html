This page explains where our numbers come from, what we check ourselves, and what the labels on each value mean. In short: most values come from the community wikis on Fandom, and only a value with a saved in-game screenshot says "Verified in game".

Where our data comes from

How we test a value in the game

  1. We use a normal account and never use exploits or scripts.
  2. We join an empty or private server when we can.
  3. We do the action, take a screenshot of the result, and repeat it if the result can vary.
  4. We save the screenshot and link it to the value in our dataset.
  5. We crop or blur other players' names before we publish a screenshot.

Egg odds and hatch rates

We show odds that the developer published, or odds from the community wiki with the "Source: community wiki" label. If we count hatches ourselves, we show it as "Observed in our N hatches", never as odds.

How the calculators work

Calculators use formulas that read values from our dataset. No number is typed into the calculator by hand. Most values still come from the community wiki, and the calculator says so under the result. If we have no value at all, the calculator says "Not available yet" instead of guessing.

How we keep data current

An update tracker watches each game's Roblox page and tells us when a game is published again. We then compare our data with the community wiki and the developer's notes and update what changed. The date next to a value is the date of the wiki data we used, not an in-game check. In-game checks are spot checks: the first one was the Steal an Egg income formula, tested with a Golden Chicken on 23 Oct 2026.

How we use AI tools

We use AI tools to help draft and edit text, check grammar, and build the site's code. AI never invents a game number, a code, or a tier placement: every number comes from the game, the developer or the community wiki, and the page shows which one with the labels above. Values we have not checked in the game say "Source: community wiki". Some item notes were drafted with AI help from the wiki data; until Ali has reviewed them, the page says "Notes drafted with AI help" under the title.

Wiki data and its licence

The game data we copy from the community wikis on Fandom is licensed CC BY-SA. We credit the wiki under every data table and in the site footer, and our changes to that data use the same licence. We write our own text and do not copy the wikis' articles or images. See Terms.

Independence

No one pays us to rank or mention anything. We have no sponsored placements.

Found a mistake?

Use Report a wrong value on any page. Fixed mistakes are listed on Corrections.

What we don't know yet

Each game page lists the rules we have not confirmed yet, under "Limits and known gaps".

Accessibility

We aim to meet WCAG 2.2 level AA. Pages work with a keyboard and with screen readers, and tables work without JavaScript. If something is hard to use, email contact@updateotter.com.
