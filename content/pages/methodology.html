This page explains where our numbers come from, how we check them, and what the labels on each value mean.

Where our data comes from

How we test a value in the game

  1. We use a normal account and never use exploits or scripts.
  2. We join an empty or private server when we can.
  3. We do the action, take a screenshot of the result, and repeat it if the result can vary.
  4. We save the screenshot and link it to the value in our dataset.
  5. We crop or blur other players' names before we publish a screenshot.

Egg odds and hatch rates

We only show odds that the developer published. If we count hatches ourselves, we show it as "Observed in our N hatches", never as odds.

How the calculators work

Calculators use formulas that read values from our dataset. No number is typed into the calculator by hand. If a value or rule is not confirmed yet, the calculator says "Not available yet" instead of guessing.

How often we re-check

An update tracker watches each game's Roblox page. After every update we re-check the values it may have changed. We also re-check each value at least once a month.

How we use AI tools

We use AI tools to help draft and edit text, check grammar, and build the site's code. AI never decides a game number, a code, or a tier placement. A person checks every fact against the game before it goes live.

Independence

No one pays us to rank or mention anything. We have no sponsored placements.

Found a mistake?

Use Report a wrong value on any page. Fixed mistakes are listed on Corrections.

What we don't know yet

Each game page lists the rules we have not confirmed yet, under "Limits and known gaps".

Accessibility

We aim to meet WCAG 2.2 level AA. Pages work with a keyboard and with screen readers, and tables work without JavaScript. If something is hard to use, email contact@updateotter.com.
