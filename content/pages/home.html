UpdateOtter is an unofficial, fan-made site with calculators and wikis for Roblox games. We show where each game value comes from and the date we last checked it.

How we check our data

  • When we test a value in the game, we keep a screenshot and label it "Verified in game".
  • Values we have not tested yet are labelled "Source: community wiki".
  • After every game update we re-check what changed.

Read more in How we verify data. Spotted a mistake? Report a wrong value.
