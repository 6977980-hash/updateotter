UpdateOtter is an unofficial, fan-made site with calculators and wikis for Roblox games. We check game values ourselves and show the date we last checked each one.

How we check our data

  • We test values in the game and keep a screenshot of each check.
  • Values we have not tested yet are labelled "Unconfirmed".
  • After every game update we re-check what changed.
